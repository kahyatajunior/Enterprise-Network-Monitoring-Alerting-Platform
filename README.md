# Enterprise Network Monitoring & Alerting Platform

A self-contained browser prototype for an enterprise monitoring platform and cloud infrastructure deployment console.

## Run

Open `index.html` in a browser.

## Included

- Real-time simulated CPU, RAM, disk, latency, bandwidth, packet loss, and online/offline state
- Server, network device, and printer monitoring cards
- Ping, port, service, SNMP, SSH, and agent-based monitoring simulations
- Critical alerts, alert suppression, email/SMS escalation simulation
- Incident creation, assignment, resolution tracking, and root cause fields
- Animated chart, topology map, glowing status indicators, and terminal panels
- Cloud VM/storage/network/cluster management simulation
- Terraform generation, deployment timeline, rollback, and Kubernetes-style cluster cards

This is intentionally dependency-free so it can run in the current empty workspace without downloading packages.
